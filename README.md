# 🎂 Age Eligibility Checker

A simple and interactive web application built using HTML, CSS, and JavaScript that checks a user's age and displays their voting eligibility status.

## 📌 About the Project

The **Age Eligibility Checker** is a beginner-friendly JavaScript project that allows users to enter their age and instantly receive a message based on their input.

The application uses conditional statements (`if`, `else if`, and `else`) to determine the user's eligibility to vote.

This project was created to practice JavaScript fundamentals, including DOM manipulation, event handling, and conditional logic.

## ✨ Features

- Age input field to enter your age.
- Checks voting eligibility based on age.
- Displays different messages for different age groups.
- Interactive Submit button.
- Simple and clean user interface.
- Custom styling with CSS.
- Merriweather Google Font integration.

## 🛠️ Technologies Used

- **HTML5** – Structure of the web application.
- **CSS3** – Styling and layout.
- **JavaScript** – Age validation and conditional logic.
- **Google Fonts** – Typography.

## ⚙️ How It Works

The application checks the entered age and displays the following messages:

| Age | Result |
|---|---|
| Below 18 | You are not eligible to vote. |
| Exactly 18 | You are eligible to vote. |
| Above 18 | Is this your first time voting? 🙃 |
